# バージョン更新チェックリスト

EpubFabric のバージョンを更新するときは、次を確認する。

- [ ] `Directory.Build.props` の `<Version>` を更新する（製品バージョンの基準値）
- [ ] `CHANGELOG.md` と `CHANGELOG.ja.md` の両方に、対象バージョンの変更内容と比較リンクを追加する（リンクの書式は下記）
- [ ] `README.md` と `README.ja.md` のインストーラーファイル名の例を更新する
- [ ] `docs/基本設計.md` の画面例に表示されるバージョンを更新する
- [ ] `src/EpubFabric.App/MainPage.xaml.cs` の情報バージョン形式を説明するコメントを更新する
- [ ] `rg` で旧バージョンが現行バージョンの例として残っていないことを確認する
- [ ] ソリューションをビルドし、全テストを実行する
- [ ] 配布物を作る場合は `scripts/build-installer.ps1 -NdlOcrModelSource <ndlocr-lite のフォルダー>` を実行し、署名する場合は `-Sign` を付ける
- [ ] リリースを依頼された場合だけ、同じ番号の `X.Y.Z` タグ（`v` なし）を作成する
- [ ] パッケージ作成を依頼された場合だけ、生成物のファイル名と製品バージョンを確認する

## タグと比較リンクの書式

タグは `v` を付けずに `0.5.0` の形で作る。0.2.3 以降のタグ（`0.2.3`、`0.3.0`、`0.4.0`、`0.5.0`）はこの形である。最初の `v0.1.0` だけが `v` 付きで、そのまま残している。

CHANGELOG の比較リンクは、実在するタグを指す。

```
[未リリース]: https://github.com/fukuyori/EpubFabric/compare/0.5.0...HEAD
[0.5.0]: https://github.com/fukuyori/EpubFabric/compare/dcd4c23...0.5.0
```

タグを作らなかったバージョン（0.1.1〜0.1.4、0.2.0〜0.2.2、0.4.1）は、バージョン番号を入れたコミットの短縮ハッシュで比較する。0.2.4 は対応するタグもコミットもない（0.3.0 のコミットにまとめられた）ため、比較リンクを置かない。

新しいバージョンを追加するときは、`未リリース`（英語版は `Unreleased`）の比較元を新しいタグへ変え、新しいバージョンの行を前のバージョンのタグ（なければコミット）から新しいタグへの比較として加える。
