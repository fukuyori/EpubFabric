# バージョン更新チェックリスト

EpubFabric のバージョンを更新するときは、次を確認する。

- [ ] `Directory.Build.props` の `<Version>` を更新する（製品バージョンの基準値）
- [ ] `CHANGELOG.md` に対象バージョンの変更内容と比較リンクを追加する
- [ ] `README.md` のインストーラーファイル名の例を更新する
- [ ] `docs/基本設計.md` の画面例に表示されるバージョンを更新する
- [ ] `src/EpubFabric.App/MainPage.xaml.cs` の情報バージョン形式を説明するコメントを更新する
- [ ] `rg` で旧バージョンが現行バージョンの例として残っていないことを確認する
- [ ] ソリューションをビルドし、全テストを実行する
- [ ] 配布物を作る場合は `scripts/build-installer.ps1` を実行し、署名する場合は `-Sign` を付ける
- [ ] リリースを依頼された場合だけ、同じ番号の `vX.Y.Z` タグを作成する
- [ ] パッケージ作成を依頼された場合だけ、生成物のファイル名と製品バージョンを確認する
